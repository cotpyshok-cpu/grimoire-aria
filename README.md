# Гримуар Арии — Хроники Хондора (Городской квест D&D)

Интерактивный городской квест-приключение в формате **Progressive Web App (PWA)**, разработанный ко дню рождения.

## 📖 Сюжет и Структура
Квест состоит из 3 взаимосвязанных актов:
- **Акт I: Врата Столичных Теней** (Астана — сбор отряда, квесты в городе, кофейни, парки)
- **Акт II: Дорога в Ночь** (Поезд Астана → Караганда — ночные беседы с Тоником, степные станции)
- **Акт III: Карагандинские Оплоты и Великий Алтарь** (Караганда — родовые печати, артефакты, финальный ритуал)

## 🛠 Технологии
- **Frontend**: Vanilla HTML5, CSS3 (Pixel-Art / RPG Retro Theme), ES6+ JavaScript.
- **Интерактивные карты**: Leaflet.js с тайлами OpenStreetMap.
- **Офлайн / PWA**: Service Worker (`sw.js`) с кэшированием всех ассетов и 29 SVG-портретов персонажей.
- **Звук**: Web Audio API (генерация 8-битных ретро-звуков и музыкальных тем).

## 🚀 Локальный запуск
Для локального тестирования требуется Node.js:
```bash
node serve.js
```
После запуска приложение доступно по адресу: [http://localhost:8080](http://localhost:8080)

## 🌐 Развёртывание
- **GitHub Pages**: автоматически собирается и публикуется через GitHub Actions (`.github/workflows/deploy-pages.yml`) из папки `app/`.
