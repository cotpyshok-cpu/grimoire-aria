## ЗАДАЧА

Создай мобильное web-приложение (PWA) «Гримуар Арии» — городской квест-приключение в стилистике D&D, посвящённое дню рождения. Игрок (девушка, играет персонажа-барда) физически перемещается по реальному городу (Караганда + Астана, Казахстан), находит точки на карте, отгадывает загадки, общается с НПС и живыми актёрами, и в финале получает сюрприз-подарок. Квест рассчитан на 2 дня и 2 города.

Рабочая папка: `C:\Quest\app` — там уже есть рабочий прототип (index.html, css/style.css, js/app.js, js/dialog.js, js/matcher.js, js/quest.js). Его можно доработать или переписать, сохранив концепцию и структуру данных.

## ТЕХНОЛОГИИ

- Чистые HTML/CSS/JS (без сборщиков и фреймворков — сайт хостится на GitHub Pages)
- Карта: Leaflet + OpenStreetMap (без API-ключей)
- Шрифт: VT323 или Press Start 2P (Google Fonts)
- Офлайн-проверка ответов: нормализация русского текста + расстояние Левенштейна (понимать опечатки, склонения, перестановку слов)
- Геолокация: navigator.geolocation.watchPosition
- Никаких серверов и баз данных — весь прогресс в localStorage

## КОНЦЕПЦИЯ И ЛОР

Приложение = «Гримуар» (волшебная книга), созданная Ильёй-Артифактором (он же — реальный мастер квеста, живой актёр). В Гримуаре заперт дух крысы **Тоника** — саркастичного призрачного компаньона:

- Тоник — главный рассказчик и проводник: ВСЕ диалоги, предупреждения, подсказки, комментарии идут от него
- Характер: саркастичный, хитрый, трусливый (панически боится ворон), обожает сыр и золото, бесконечно предан игроку (игрок когда-то спас его)
- Стиль речи: «Только не отдавайте меня воронам!», «Этот алхимик выглядит подозрительно... спроси про сыр!»
- Портрет: пиксель-арт призрачной крысы в шляпе волшебника

Сюжетный каркас: злодей **Безликий** (древний дух-перевёртыш, трагический антагонист в маске) пытается прорваться в мир людей через Алтарь в Караганде. Собрать **3 печати** (Старейшины таверны, Гильдия Алхимиков, Клан Хранителей Печатей — это живые актёры в ролях семейных родственников), сразиться в торговой дуэли с наёмниками за **Ключ от Алтаря**, финал — изгнание Безликого и дверь с настоящим подарком.

## ЭКРАНЫ И МЕХАНИКИ

1. **Стартовый экран** — заголовок, кнопка «НАЧАТЬ». Клик обязателен (браузер разрешает звук только после взаимодействия). Место для лорного пролога.
2. **Карта** — весь экран, маркеры локаций эмодзи/иконками (🚪 старт, 📜 загадка, 🧙 живой актёр, 🔮 финал). Текущая целевая локация подсвечена (пульсация/крупнее). Позиция игрока — золотая точка. Пройденные — серые галочки.
3. **Типы локаций** (в данных — поле `type`):
   - `start` — сюжетный пролог от Тоника
   - `riddle` — текст загадки + ввод ответа; подсказки выдаются по кнопке «Вдохновение Барда» (limit 3 за игру); при неверном ответе Тоник подколами ведёт к правильному
   - `mentor` — живой актёр: диалог Тоника → текст испытания → поле ввода (ответ проверяет человек, в данных `freeForm: true` — принимается любой ввод)
   - `final` — экран финала с финальным текстом и поздовением
4. **Диалоги** — окно в стиле старых RPG: имя НПС, пиксельный портрет, текст печатается посимвольно (typewriter), тап ускоряет/показывает целиком, «▼ далее» мигает. Хранение: массив строк.
5. **Геолокация** — при входе в радиус точки (поле `radius`, ~50–80 м) локация открывается автоматически. Кнопка-фоллбек «Я на месте, открыть вручную» (GPS в бетонных стенах/музеях сбоит — это критично для многодневного квеста).
6. **Музыка** — фоновый трек зациклен, громкость ~35%, кнопка mute. Порядок треков меняется на финале (эпичный).
7. **Прогресс** — localStorage: пройденные локации, потраченные подсказки, чтобы закрыть-открыть телефон и продолжить.
8. **HUD** — верхняя плашка: название квеста, «Локация X / Y».

## ДИЗАЙН (строго)

- **Пиксель-арт фэнтези**, вечерний «тавернный» оттенок
- Палитра: фон глубокий тёмно-коричневый/чёрный (#0b0804, #1a1408), панели #2b1f0e, основной акцент золото #d4af37, деталь бордово-красный #8f1f1f, текст пергаментный #e8d9a0
- Границы панелей: толстые (3–4px) золотые, с жёсткой тенью 3px чёрной (пиксельный эффект псевдо-3D), без скруглений
- Сепия/тёмный фильтр на карте (leaflet filter: sepia(.35) saturate(.7))
- Шрифт VT323 размеров 18–26px — читаемость на телефоне первична
- Анимации: bob (покачивание маркеров), pulse (мигающие элементы), по желанию — мерцающие частицы-искры на фоновых экранах
- Мобильная ориентация phone-first, всё в viewport без прокрутки, safe-area отступы

## СТРУКТУРА ДАННЫХ КВЕСТА (js/quest.js)

```js
const QUEST = {
  title: "...",
  music: "music/theme.mp3",
  locations: [{
    id, type: "start|riddle|mentor|final",
    name, coords: [lat, lng], radius,
    intro: ["реплики Тоника..."],           // диалог при входе
    riddle / challengePrompt,               // вопрос
    answers: ["вариант1", "вариант2"],      // для riddle
    freeForm: true,                          // для mentor (актёры решают)
    hints: ["подсказка1", "подсказка2"],
    reward: ["реплики после успеха"],
    npcName, npcPortrait,                   // для mentor
    finalText                               // для final
  }]
}
```

Проверка ответа: normalize (lowercase, ё→е, убрать пунктуацию и мусорные слова «и, в, на, у, от») → сравнение по словам через Левенштейна с порогом ~34% длины слова + допуск перестановки слов и частичного вхождения. Цель: игрок, написавший «мост шмидта» вместо «блан мост лтинант шмидта», должен пройти.
